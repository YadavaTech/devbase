# Frequently Asked Questions (FAQ) – DevBase

Find answers to common questions about DevBase, its developer tools, software development resources, AI-powered coding capabilities, cloud services, security solutions, licensing, and technical support.

DevBase is a developer-focused ecosystem being built to help developers, freelancers, startups, and software agencies build, integrate, secure, and scale software applications through reusable development resources and tools.

## 1. What is DevBase?

DevBase is a developer ecosystem focused on software development tools, reusable code resources, AI-assisted coding, cloud infrastructure, and application security.

The goal of DevBase is to simplify the software development lifecycle by bringing useful developer resources and services into one ecosystem.

## 2. What products and services does DevBase offer?

DevBase is organized around four core areas:

- **DevBase Build:** Developer tools, reusable code, boilerplates, starter kits, and software development resources.
- **DevBase Cloud:** Cloud-based backend services and infrastructure tools designed to support application development and deployment.
- **DevBase AI:** AI-assisted coding capabilities intended to help developers understand code, generate implementations, debug issues, and improve development workflows.
- **DevBase Shield:** Application security solutions focused on monitoring, identifying suspicious activity, and helping developers improve application protection.

Availability may vary by product. Refer to the official DevBase website and product documentation for current release information.

## 3. Is DevBase open-source?

DevBase currently combines publicly available documentation with private products and resources. Not every DevBase product or component is open-source.

Before using, modifying, redistributing, or contributing to a particular resource, review its applicable license and usage terms.

## 4. Who can use DevBase?

DevBase is designed for a broad range of software development professionals, including:

- Independent developers and programmers.
- Freelancers working on client projects.
- Startups building MVPs and SaaS applications.
- Software development agencies.
- Android and web application developers.
- Backend developers and API engineers.
- Teams looking to reuse development components and streamline workflows.

Whether you are building a personal project, a commercial application, or software for clients, DevBase aims to provide relevant development resources.

## 10. What is DevBase Shield?

DevBase Shield is the application security component of DevBase.

Its goal is to help developers improve application protection through security-focused tools and monitoring capabilities. Depending on the available release, these may include suspicious activity monitoring, security event visibility, and integration guidance.

No client-side SDK can guarantee complete protection against every attack. Effective application security also requires secure backend implementation, server-side validation, appropriate access controls, and ongoing maintenance.

Refer to the official documentation for currently supported security features.
